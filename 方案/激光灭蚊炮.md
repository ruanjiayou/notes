## 计算
- 测距与激光精度
  - 激光焦点深度： 光斑直径增大到2倍，能量密度降为1/4 无法用固定4m焦距覆盖3~5m范围
  - 实时感知：蚊子速度1~2m/s，调焦需要在0.1s内完成
  - 微型直线舵机(SG90改)：行程10mm
  - 调焦： Δs = f²/(D₂-D1)
- 舵机速度
  - 加速度：α= 2n/(mR²)
  - ω = αt = 2nt/(mR²) rad/s  角速度按较快 90°/s = 15rpm ≈ 1.57rad/s
- 蚊子拍摄
  - 画面覆盖宽度： width = 2 * d * tan(FOV /2) 
  - tan(35°) ≈ 0.7
  - d = 2 ; FOV = 70° ; 2952*1944
  - 宽度方向的分辨率为：2592像素 / 2.24米 ≈ 1157 像素/米
  - 4mm蚊子：0.004米 * 1157像素/米 ≈ 4.6个像素
