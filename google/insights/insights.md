# 笔记



| **对比维度** | **YouTube Data API v3**                   | **YouTube Analytics API**                         | **YouTube Reporting API**                           |
| ------------ | ----------------------------------------- | ------------------------------------------------- | --------------------------------------------------- |
| **定位**     | **公众/管理 API** （元数据与实时状态）    | **分析 API** （交互式查询面板）                   | **大数据 API** （批量全量导出行数据）               |
| **实时性**   | ⚡**近实时** （几秒到几分钟延迟）          | 🐢**延迟 24~48 小时**                              | 🐢**延迟 24~72 小时**                                |
| **清洗粒度** | **粗粒度 / 初步清洗**（为了前端快速显示） | **深度清洗 / 精确归因**（过滤剔除无效与作弊流量） | **深度清洗 / 支持重核**（包含曝光量、最终财务结算） |
| **数据维度** | 仅视频/频道总数（例如累积 Views）         | 包含时间、国家、订阅状态、设备等                  | 维度最全（含 Impressions、CTR 等）                  |
| **修正机制** | **无** （直接覆盖最新总数，无法回溯历史） | 无历史修正概念，仅按区间查最新                    | **有** （后续生成的 CSV 自动带上历史修正行）        |
